# Third-party software

Simulatics is MIT-licensed (see `LICENSE`). It does not bundle any third-party code: the packages below are
installed separately by `pip` from their own distributions, under their own licences, and three.js is loaded
by the browser from a CDN. This file records what the project depends on and why the MIT licence is
compatible with all of it. Audited 2026-11-18 from the installed package metadata.

## Data and models

- Robot models, CAD meshes, reference motions and trained policies in this repository are generated by
  Simulatics itself and are covered by its MIT licence.
- No motion-capture datasets are included. If you import BVH files (for example LAFAN1, which is
  CC BY-NC-ND, or AMASS, which is research-only), their licences apply to them and to anything you derive
  from them.
- Robots you import (for example from MuJoCo Menagerie) keep their own licences. The robot library
  (`simulatics/robots.py`) downloads models on demand and does not redistribute them; each downloaded
  folder keeps its LICENSE: PNDbotics Adam Lite is MIT (Copyright (c) 2023 pndrobotics), Unitree Go2 is
  BSD-3-Clause (Copyright (c) 2016-2022 Unitree Robotics).

## Cited papers

Source comments and `docs/METHODS.md` cite published papers by author and year. Those works belong to
their authors; the implementations in Simulatics are original code written from the published
descriptions, and no code is taken from them.
